codeintel-fuzz-test-generator

The Tensile Bench. A fuzz test generator that reads one Python module and writes generated test cases for its top level functions, each one fed value after value drawn at random.

The repository main.py
Read, never runThe target module is parsed from its syntax tree only; it is never imported or executed
Top level onlyOnly functions defined at the module top level receive tests; methods and nested functions do not
Unseeded randomThe random module is never seeded, so two runs differ and a failing case has to be saved from its own run
Printed verdictsGenerated tests print their outcomes inside try blocks, so a generated file exits 0 even when a case has failed

Usage

python3 main.py MODULE_PATH [--num_tests N] [--string_length N] [--int_min N] [--int_max N] [--output_file FILE]

Parameter values are drawn from the annotation on each parameter: int, float, str, and bool are honoured, and every other annotation, list and dict included, falls back to str, so a generated call can pass a string where the author expected a container. A target that cannot be read or parsed, or that defines no functions of its own, fails the run at exit 1 and writes nothing. The repo also carries a SECURITY.md beside the code.

OptionWhat it does
module_pathThe module to generate tests for. Required. The README parameter list omits it; the code requires it.
--num_testsGenerated tests per function. Default 10.
--string_lengthLength of generated string values. Default 10.
--int_min / --int_maxThe integer range drawn from. Defaults -100 and 100.
--output_fileSend the generated tests to a file instead of stdout.

What a quiet run means

  • A generated test file that runs clean has printed its outcomes, not proven them: whoever runs it must read the printout to know whether a case failed.
  • Because the random draws are never seeded, a failure found once cannot be reproduced by simply running the generator again.
  • Functions below the top level, methods and nested functions, are never given tests at all.

Requirements

Python, standard library only. The requirements file is a comment saying so, and noting that the bandit, flake8, pylint, and pyre-check entries that stood there before were never imported or run by this tool.
